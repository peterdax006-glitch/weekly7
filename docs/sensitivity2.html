How to read this

Each setting is changed alone while everything else stays at the champion. Effect is the change in average weekly return over the champion; the interval comes from the year-by-year effects; stability is the share of years the change pointed the same way. With 106 values tried, some will look good by luck, so a single value only counts when |t| ≥ 3.50 (Bonferroni). Alternatives that lost are listed in full.
