Build the system that learns WHEN patterns work:
1. Break explanation: for every pattern whose timeline shows a flip/stop, search what CHANGED around the break using only information available before and at the break (market context: volatility level/term, trend, breadth, dispersion, rates/macro with publication lags, liquidity, crowding = how many other patterns/stocks share the condition, the pattern's own age and recent hit rate). Produce plain-language explanations ("stops working when short-term fear exceeds long-term fear") with evidence counts, never stock identities.
2. Reliability model: a meta-model POOLED across patterns and time that predicts P(pattern holds next period | context now, pattern meta) - walk-forward, past-only (only matured evidence), calibrated (Brier/ECE vs base rate).
3. Gating instead of discarding (C60): plug into B26's view(gate=...) so a pattern is used only in conditions where it is predicted reliable, and switched off (weight -> 0) where predicted unreliable - the pattern stays in memory. Also flag patterns whose reliability is itself unpredictable (then the C59 discard applies).
4. Evaluation, all past-only and judged out of sample: (a) gated vs always-on vs discard-after-break on the real miner's pattern timelines (weekly pattern returns); (b) through the learning harness (engine/learning_delta.py, B22's repeated-run curve and transfer) once B22/B26 land; (c) per era. Report gains with CIs.
5. Planted worlds (tests): a pattern whose validity depends on a hidden-but-observable regime variable (the meta-learner must find the variable, gate it, and beat both always-on and discard); a pattern that breaks at random times (must be judged unpredictable -> discarded, no fake gating gain); a family of patterns sharing one break driver (pooling must help); a future-leak canary (a context feature that peeks at the next period must be caught).
Use a family-wise bar for explanations (many candidate drivers are searched). Long real runs DETACHED with checkpoints, RAM >= 2.5 GB. Never run git; never kill by name.
