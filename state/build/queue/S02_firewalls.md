Build: Eight independent layers (data, time, memory, identity, provenance, experiment, evaluation, code-version) behind one fail-closed gate returning a per-layer verdict. Identity firewall: ticker/date/year permutation, stock/sector/episode substitution, sequence scrambling harness that runs any learner callable twice and flags collapse. Reproducibility: code/data/config hash + seed + worker config + memory snapshot + experiment id; mismatch labels the result.
